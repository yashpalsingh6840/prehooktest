## Where things live

- `TestDoubles/` (in `{Package}.Tests/`) -- `FakeUnitOfWork`/`RecordingNotifier`/
  `PackageHarness`, generated fresh for this package. No SQL Server involved:
  `dotnet test --filter Category!=Integration` never opens a real connection.
- `gaps/<Package>/` (under `--out` root) -- one self-contained work packet per Tier-1/2
  gap this package reported; `gaps.json` is the index.
- `fills/`/`fills-library/` -- human-authored answers, never written by `ssisx`; applied
  via `ssisx apply-fills`.
- `appsettings.Development.json` + `TestData/` -- a package-relative sample-data override
  for local `dotnet run` (`DOTNET_ENVIRONMENT=Development`); `TestData/` is empty until a
  `LOCAL-DATA` fill supplies real files.
